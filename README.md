# 도깨비 문파 홈페이지

도깨비의세계 문파용 팬 홈페이지입니다. 달밤의 한옥 마을과 도깨비불을 배경으로 한 실사풍 랜딩 페이지에 아래 기능이 있습니다.

- **문파 소개**: 문파 이름·레벨, 공지, 전투력 순위, 이번 주 성장, 주간 결산 수상자, 엽전 분배 기준표
- **문파원**: 엑셀 시트처럼 한눈에 보는 문파원 현황 — 직위, 닉네임, 전/현 전투력, 성장, 주별 콘텐츠 참여(요신·결계지·신기·미혹·분신·디코), 점수, 누적엽전·보유엽전(문파원에게만). 지난 결산 목록
- **문파창고**: 문파 상점에서 사 둔 물품을 엽전으로 신청 → 운영진 승인 시 재고와 엽전 차감
- **내 정보**: 닉네임 변경(같은 닉네임의 명단과 자동 연결), 이번 주 참여, 엽전 내역
- **도술덱**: 문파원 누구나 도술덱을 올리고(도술 8칸 + 궁극기 1칸. 같은 스타일 3개 이상이면 그 스타일 궁극기, 여러 개면 골라서) 서로 🏮 추천할 수 있습니다. 운영진은 '문파 추천 덱'으로 지정해 맨 위에 보여 줍니다. 덱은 로그인하지 않아도 볼 수 있습니다. 도술 93개와 스타일별 궁극기 12개 목록은 `src/data/skills.ts` (10/21 패치 기준)에서 고칩니다.
- **방명록**: 손님도 이름을 적어 남길 수 있고, 지우기는 작성한 문파원과 운영진만 할 수 있습니다. 같은 이름으로 30초 안에 다시 쓰지 못합니다.
- **방문자 수**: 하단에 오늘·전체 방문 수를 보여 줍니다. 브라우저마다 하루 한 번만 세고, 개인정보는 저장하지 않습니다.
- **관리** (문주·부문주): 신청 처리, 참여 기록(표에서 바로 체크)·엽전 조정, 주간 결산(전투력 스크린샷 갱신 + 엽전 분배), 명단 관리(엑셀 붙여넣기, 계정 연결, 가입 승인, 권한 변경은 문주만), 창고 물품·재고, 문파 정보, 점수·보너스 기준(문주만)

### 문파원 명단과 계정

- **명단**(`roster`)은 운영진이 관리하는 게임 문파원 목록입니다. 홈페이지에 가입하지 않은 문파원도 들어갑니다.
- 엑셀 문파원 시트를 머리글부터 복사해 **관리 → 명단 관리**에 붙여 넣으면 직위·닉네임·현 전투력을 넣고, 누적엽전이 있으면 보유 엽전을 그 값에 맞춥니다(차이만큼 '조정' 기록).
- 구글로 가입한 계정이 승인되면 **같은 닉네임의 명단과 자동으로 연결**됩니다. 닉네임이 다르면 명단 관리에서 직접 연결합니다. 연결된 계정만 창고를 신청할 수 있습니다.

### 문파 엽전 분배

```
내 분배 엽전 = 그 주 문파 엽전 × 내 점수 ÷ 모든 문파원 점수 합계   (1전 미만 버림, 남는 엽전은 문파에 남음)
```

- **참여 점수**: 요신 토벌령·결계지 방어·신기 쟁탈전·미혹의 정원 각 1점(주 1회), 분신(분신으로만 참여한 콘텐츠 수)과 디코는 횟수 × 1점. 한 주는 **수요일 시작**이고, 운영진이 참여 기록 표에서 칸을 눌러 1점을 줍니다.
- **주간 보너스**: 결산 때 **최고 전투력 +300전**, **최고 성장 +300전**(지난 결산 대비, 동점이면 모두). 문주가 바꿀 수 있고, 0이면 지급하지 않습니다.
- **누적엽전**은 받은 엽전 합계, **보유엽전**은 창고에 쓴 엽전을 뺀 잔액입니다.

### 전투력 갱신과 주간 결산 (매주 수요일)

전투력은 운영진만 바꿀 수 있습니다(DB에서도 막음). 게임에는 전투력을 조회할 공식 API가 없어서 문파원 목록 스크린샷의 글자를 읽어(OCR, Tesseract.js) 갱신하며, 이미지는 브라우저 안에서만 처리되고 서버로 올라가지 않습니다.

1. **관리 → 주간 결산**: 문파원 목록 화면을 여러 장 캡처해 올리면 명단의 닉네임을 찾아 전투력을 읽습니다. 값을 확인·수정한 뒤 저장합니다.
2. 같은 화면 아래 **주간 결산**에서 지금 게임의 **문파 엽전 보유량**을 입력합니다. 지난 결산 때 기록된 보유량과의 차액이 그 주 분배 엽전으로 자동으로 들어갑니다(문파 상점에서 쓴 엽전이 있으면 고쳐 적기). 1인당 분배 엽전과 보너스 대상을 확인하고 결산하면 엽전이 지급되고, 그때의 보유량이 다음 주 계산용으로 남습니다. 보유량은 문파 소개 화면에도 보입니다.
   - 한 주(수~화)에 한 번만 결산합니다. 비교할 지난 값이 없는 문파원은 성장 보너스 대상이 아닙니다.
   - 잘못 결산했으면 가장 최근 결산을 취소하고(분배·보너스 회수) 다시 할 수 있습니다.
3. 참여 점수·보너스 엽전은 **관리 → 문파 정보**에서 문주가 바꿀 수 있습니다.

## 바로 써 보기 (체험 모드)

```bash
npm install
npm run dev
```

`.env` 가 없으면 **체험 모드**로 실행됩니다. 로그인 화면의 체험 계정 버튼(문주/부문주/문파원/가입 대기자)으로 모든 화면을 둘러볼 수 있고, 데이터는 그 브라우저에만 저장됩니다.

## 실제 운영 설정 (Supabase)

1. [supabase.com](https://supabase.com) 에서 무료 프로젝트를 만듭니다.
2. 대시보드 **SQL Editor** 에 [`supabase/schema.sql`](supabase/schema.sql) 내용을 전부 붙여 넣고 실행합니다.
   이미 운영 중인 DB는 schema.sql 을 다시 실행하지 말고, [`supabase/migrations/`](supabase/migrations) 의 새 파일만 순서대로 실행합니다.
3. **Project Settings → API** 의 `Project URL` 과 `anon public` 키를 `.env` 에 넣습니다.
   ```bash
   cp .env.example .env
   ```
4. **Authentication → URL Configuration** 의 Site URL 을 홈페이지 주소로 바꿉니다. (인증 메일 링크가 여기로 돌아옵니다.)
5. 문주가 **가장 먼저 가입**하세요. 첫 가입자는 자동으로 문주가 되고, 이후 가입자는 운영진이 승인해야 합니다.

> 이메일 인증이 번거로우면 Authentication → Providers → Email 에서 *Confirm email* 을 끌 수 있습니다.

## 권한 규칙

| | 비로그인 | 가입 대기 | 문파원 | 부문주 | 문주 |
|---|:-:|:-:|:-:|:-:|:-:|
| 문파 소개·문파원 목록 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 콘텐츠 참여·엽전 보기 | | | ✅ | ✅ | ✅ |
| 창고 신청 | | | ✅ | ✅ | ✅ |
| 명단 관리·가입 승인·참여 기록·엽전 조정·전투력 갱신·주간 결산·창고 관리·신청 처리 | | | | ✅ | ✅ |
| 권한 변경·점수/보너스 기준 변경 | | | | | ✅ |

규칙은 화면이 아니라 DB(RLS 정책과 RPC 함수)에서 검사하므로 화면을 우회해도 지켜집니다.

## 배포 (GitHub Pages)

1. 저장소 **Settings → Pages → Source** 를 *GitHub Actions* 로 바꿉니다.
2. **Settings → Secrets and variables → Actions** 에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 를 등록합니다.
3. `main` 에 푸시하면 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) 이 빌드해서 배포합니다.

## 구조

```
src/
  pages/        화면 (Home, Members, Warehouse, MyPage, Admin, Login)
  components/   레이아웃, 메인 비주얼(Hero)
  assets/       메인 이미지, 로고
  lib/          types, supabaseBackend(실제 DB), demoBackend(체험 모드), auth
supabase/schema.sql   테이블, 권한(RLS), 명단 연결·창고 신청/승인·주간 결산(엽전 분배) 함수
supabase/migrations/  운영 중인 DB에 순서대로 적용하는 변경분
```

## 참고

- 글꼴: Noto Serif KR, Noto Sans KR (Google Fonts, SIL OFL 1.1)
- 메인 이미지(`src/assets/hero*.webp`)는 AI(Higgsfield, GPT Image 2.5)로 새로 만든 그림입니다.
- 도술·궁극기·스타일 아이콘(`src/assets/skills/`, `src/assets/styles/`)은 도깨비지지(kkaebi.gg) 도술 도감에서 받아 온 것으로, 원 저작권은 게임사(슈퍼캣·카카오게임즈)에 있습니다.
- 창고 물품 아이콘(`src/assets/items/`)은 게임 문파 상점 화면에서 잘라낸 것으로, 권리는 원저작자(슈퍼캣·카카오게임즈)에게 있습니다.
- 도깨비의세계 공식 사이트가 아닌 문파 팬 홈페이지입니다.
